# 《飞白》卡牌效果说明（仅按当前代码实现）

> 本文档**只描述 `CardDB` + `Combat.playCard` / `playAllAttacks` / 相关公共函数在运行时实际执行的行为**，不保证与卡面中文描述逐字一致。  
> 不含：平仄、耗气、稀有度等与效果逻辑无关的字段。

---

## 全局：打出卡牌时（`Combat.playCard`）除各牌 `effect()` 外还会发生什么

1. **消耗能量**：按手牌项上的 `costOverride`（若有）或牌库定义的费用扣气。  
2. **势**：若该牌 `isAttack: true`，势 +1（上限 10）。  
3. **平仄**：若当前未处于「无视平仄」（`ignorePZ`），把本牌 `type` 推入平仄历史（最多 5 条），重绘平仄条并检测诗句触发。  
4. **去向**：镜像牌或 `toExhaust: true` 的牌进**沉沙堆**；否则进**弃牌堆**。（本牌已先从手牌移除。）  
5. **之后执行**该牌的 `effect()`。  
6. **功法/被动钩子（在 `effect()` 之后、`renderHand` 前，部分带 `setTimeout`）**：  
   - **唇枪舌剑**（`chunQiang`）：若本牌是「仄」且**不是** `c44` 本体，约 100ms 后对**一名敌人**再打一次伤：基础 **-5**（非固定伤，吃角色/武器力、势暴击、己方虚弱、敌方易伤等）。目标为「随机另一名存活敌人」；若没有其他存活敌人则打当前主目标。  
   - **固若金汤**（`guRuo`）：若本牌是「平」且**不是** `c45` 本体，约 100ms 后 `addBlock(-4)`（即基础 -4 再加成御，总加成见 `addBlock`）。  
   - **峨眉剑法**（`emei`）：若本牌 `isAttack`，计数 +1；满 3 则清零并抽 1 张。  
   - **刀光剑影**（`daoGuang`）：若牌名含字符 **`剑`** 且当前不在「重复施法」保护内，约 400ms 后**再调用一次同一 `effect()`**（不扣气、不推进平仄、不再走上述钩子；若 `effect` 内再次满足刀光条件会嵌套 `_inRepeat` 保护，一般不会无限叠）。

**重要**：通过 **`Combat.playAllAttacks`**（破阵子、万剑归宗）或 **念奴娇自动打出**、`openCardPicker` 回调等路径**直接调用 `cd.effect()`** 时，**不经过**上述第 1～6 步的 `playCard` 流程（无扣气、无平仄推进、无唇枪/固若/峨眉/刀光的「打出钩子」）。

`dealDmg`（非固定）：基础值 + 角色力 + `combatStr` + `turnStr` + 武器力 + `turnDmgMod`，下限 0；势满 10 时本次伤害 ×1.5 并清零势；`dmgDouble` 时再 ×2；己方虚弱 ×0.7；敌方易伤 ×1.5；先扣敌方 **持守（block）** 再扣血；若启用 **流星落月**，对当前目标的**溢出伤害**会以**固定伤**形式溅射到另一名随机存活敌人。  

`addBlock`（非固定）：基础值 + 角色御 + `combatDef` + `turnDef` + 武器御，下限 0，加到玩家 `block`。  

`dealDmgAll`：对**当前每一名存活敌人**各结算一次同参数的 `dealDmg`（批量结束时统一移除死亡单位）。

**目标选择**：未指定下标时，`dealDmg` 使用「当前选中敌人索引」若存活，否则第一名存活敌人。拖拽落在某敌人格上会更新选中索引；否则在仅命中「打出区」时用主目标。

## 按卡牌 ID 列举

### c1 — 横劈（武卡）

- **实现**：`dealDmg(0)`，对当前主目标造成**可加成**的 0 基础伤（仍吃全套伤害修正与势暴击等）。

### c2 — 闪避（功卡）

- **实现**：`addBlock(0)`，获得「基础 0 + 御等」的持守。

### c3 — 蝶恋花（词牌）

- **实现**：本回合 `turnDmgMod -= 3`；`energy += 2`。

### c4 — 点水（功卡）

- **实现**：`draw(1)`。

### c5 — 绣剑（装备卡）

- **实现**：`effect` 为空；卡面「6 力 6 防」由数据/装备体系在别处处理（打出时不执行逻辑）。

### c6 — 破阵子（词牌）

- **实现**：`playAllAttacks()` 后立即 `cantDmgNextTurn = true`（下回合玩家回合开始时进入「止战」类不可造成伤害状态）。  
- **说明**：见上文 —— `playAllAttacks` **不会**触发 `playCard` 的势/平仄/唇枪/固若/峨眉/刀光等钩子；但对每个被打出武卡会单独 `effect()`、单独加势（在 `playAllAttacks` 内 +1/次），并把牌送进弃牌/沉沙。

### c7 — 定风波（词牌）

- **实现**：`takeDmg(7, true)`（无视玩家持守）；对 **`Combat._primaryTargetIdx()`** 指向的敌人若仍存活则 `stun = true`（囿于旋风）。

### c8 — 水调歌头（词牌）

- **实现**：立即 `dealDmg(0)`，约 200ms 后再 `dealDmg(0)`（两次均对主目标、可加成）；接着 `draw(1 + State.agi)`。

### c9 — 念奴娇（词牌）

- **实现**：打出后进沉沙；`nianNuJiao = true`。之后每回合玩家在 `startTurn` 中：先 `takeDmg(1, true)`，再尝试从**弃牌堆**随机挑一张**可打出**牌直接执行 `effect()`（不经过 `playCard`）；该牌若 `toExhaust` 进沉沙否则回弃牌。

### c10 — 满江红（词牌）

- **实现**：`draw(1)`；`dmgDouble = true` 且 `takeDmgDouble = true`（本回合造成伤害与受伤均可翻倍，具体在 `dealDmg` / `takeDmg` 中）。

### c11 — 习武（功卡）

- **实现**：`turnStr += 1`，`turnDef += 1`，刷新 UI。

### c12 — 刺击（武卡）

- **实现**：`dealDmgAll(-1)`，对**每个存活敌人**各结算一次基础为 -1 的可加成伤害（每体单独势/暴击判定顺序随循环而定）。

### c13 — 舞剑（武卡）

- **实现**：`dealDmg(1, true)`（**固定** 1 点基础，不吃力）+ `draw(1)`。

### c14 — 挂剑（武卡）

- **实现**：`dealDmg(1)`（非固定）；打开手牌选择器，选 1 张置入沉沙（索引倒序处理）；选完 `renderHand`。

### c15 — 撩剑（武卡）

- **实现**：连续三次 `dealDmg(4, true)`（固定 4），间隔 150ms、300ms（三次均对**同一目标逻辑**：未指定下标 = 主目标）。

### c16 — 抗衡（功卡）

- **实现**：`addBlock(3)`。

### c17 — 斡旋（功卡）

- **实现**：`draw(1)`，标注为固定抽牌（`isFixed` 仅用于描述渲染，此处 `draw` 无防加成含义）。

### c18 — 缮甲（功卡）

- **实现**：本场战斗计数 `shanjia` 每打出 +1；本牌 `addBlock(当前 shanjia 值)`（首次为 1，递增）。

### c19 — 磨刀（功卡）

- **实现**：`addBlock(-2)` + `turnStr += 1`。

### c20 — 伏击（武卡）

- **实现**：`takeDmg(1, true)` + `dealDmg(-1)`。

### c21 — 双斩（武卡）

- **实现**：`dealDmg(-3)`，约 200ms 后再 `dealDmg(-3)`（同主目标）。

---

### c22 — 歃血为盟（功卡）

- **实现**：进沉沙；`takeDmg(1, true)`；对每个 **hp>0** 的敌人 `weak += 3`、`vuln += 3`（敌方身上的虚弱/易伤状态，用于敌方出伤减免 / 承伤加深，由战斗内系统读取）。

### c23 — 一转攻势（功卡）

- **实现**：进沉沙；`yiZhuan = true`。之后每累计通过 `Combat.onStrLost` 登记 **3 点**「失力」，本回合 `turnStr +1`（具体与 `c24` 等调用 `onStrLost` 的牌配合）。

### c24 — 束手就擒（功卡）

- **实现**：进沉沙；`turnStr -= 2`；`onStrLost(2)`；Toast「敌我力量削弱」。**代码未修改任何敌人属性。**

### c25 — 厉兵秣马（功卡）

- **实现**：手牌中加入一张 **黩武**（`c_duwu`）；`draw(3)`（抽到牌**不**强制为固定费）。

### c26 — 万夫莫开（功卡）

- **实现**：`addBlock(8)`；对每个存活敌人 `weak += 1`（卡面写「虚弱」在敌侧表现为 `enemy.weak`）。  

### c27 — 摧枯拉朽（武卡）

- **实现**：**保留**（`keep: true`，仅标记；回合结束不入弃牌逻辑在别处若未单独实现则与 `CardDB` 一致）；在**存活敌人**中取 **`maxHp` 最大者**为「参照敌人」，伤害基数 `5 + floor((1 - hp/maxHp) * 10) * 3`，对该敌人实例在 `enemies` 数组中的下标施放 `dealDmg(d, false, idx)`。

### c28 — 白虹贯日（武卡）

- **实现**：进沉沙；先 `dealDmgAll(5)`（对全体各 5 基础可加成）；再在**仍存活**敌人里取 **当前血量 `hp` 最高**者（并列取先遍历到的），对其再 `dealDmg(5, false, bestI)`。

### c29 — 峨眉剑法（功卡）

- **实现**：进沉沙；`emei = true`，仅启用 `playCard` 路径下的武卡计数抽牌（见全局）。

### c30 — 以逸待劳（功卡）

- **实现**：`addBlock(5)`；`nextTurnEnergy = 2`（下回合开始加气）。

### c31 — 一剑封喉（武卡）

- **实现**：`dealDmg(17)`。

### c32 — 波诡云谲（功卡）

- **实现**：进沉沙；**仅** `draw(1)`。**无**「只抽武卡」「0 费」等筛选或修改。

### c33 — 流星落月（功卡）

- **实现**：进沉沙；`liuXingLuoYue = true`。此后每次 `dealDmg` 对某一敌人若产生**溢出伤害**，溢出部分以 **`dealDmg(overflow, true, 随机另一敌人)`** 结算（不再连锁溅射）。  

### c34 — 坚壁清野（功卡）

- **实现**：进沉沙；`keepBlock = 15`（下回合开始持守保留逻辑在 `startTurn`）。

### c35 — 付之一炬（功卡）

- **实现**：打开手牌选 1 张入沉沙，确认后 `draw(1)`；**若打开选择器时手牌已为 0**（除刚打出的本牌外），额外 `draw(1)`。选牌与抽牌顺序以代码为准。

### c36 — 封刀挂剑（功卡）

- **实现**：进沉沙；`fengDao = true`，在 `onStrLost` 被调用时抽 2（与失力类效果联动）。

### c37 — 七步成诗（功卡）

- **实现**：进沉沙；**仅** `Game.showToast('寻得残卷！')`。**未**向 `State.poetry` 或 `PoetryDB` 写入任何诗句。

### c38 — 投笔从戎（武卡）

- **实现**：`dealDmg(0)`；`ignorePZ = true`（本牌已入平仄史后，后续同回合打牌是否仍记平仄以代码为准——本旗在打出**后**置位，下一张起不计平仄）。

### c39 — 拔山扛鼎（功卡）

- **实现**：进沉沙；`combatStr += 4`（本场战斗有效）。

### c40 — 文思泉涌（功卡）

- **实现**：记录 `pzHistory.length` 为 `count`，清空平仄历史并重绘；循环 `count` 次 `addBlock(0)`（每次相当于「基础 0 + 御加成」的持守）。

---

### c41 — 万剑归宗（功卡）

- **实现**：进沉沙；`playAllAttacks({ withMirror: true })`（见全局与 `playAllAttacks`：逐张武卡 `effect`、势+1、延迟生成镜像 0 费）。**不经过** `playCard` 钩子。

### c42 — 城焚烬余（武卡）

- **实现**：进沉沙；将**当前手牌全部**弹入沉沙；`X = max(1, 沉沙堆总张数)`；在 **i = 0 … X-1** 每间隔 200ms 调用一次 **`dealDmgAll(-3)`**（每一波对**当时**全体存活敌人各打一遍可加成 -3）。

### c43 — 折戟沉沙（功卡）

- **实现**：进沉沙；从沉沙堆选至多 2 张回手（弹窗）。  

### c44 — 唇枪舌剑（功卡）

- **实现**：进沉沙；`chunQiang = true`。本身为「仄」打出时**不会**触发自己的 -5 钩子（`cd.id !== 'c44'`）。

### c45 — 固若金汤（功卡）

- **实现**：进沉沙；`guRuo = true`。本身为「平」打出时**不会**触发自己的 `addBlock(-4)`（`cd.id !== 'c45'`）。

### c46 — 案剑瞋目（功卡）

- **实现**：进沉沙；`energy += 3`；`draw(3)`；`combatStr += 3`；`deathCountdown = 3`（每回合玩家开始时递减，到 0 则玩家 hp 置 0 并结算死亡）。

### c47 — 刀光剑影（功卡）

- **实现**：进沉沙；`daoGuang = true`（仅对名字含 **「剑」** 且经 **`playCard` 打出的牌**生效）。

### c48 — 金蝉脱壳（功卡）

- **实现**：进沉沙；取 `\_prevSnapshot || \_snapshot`；若无则 Toast 失败；否则将 `State.hp`、`State.momentum` 与 `State.combat.player` **浅拷贝**替换为快照内容，`\_prevSnapshot` 清空；**不**还原手牌/牌堆/平仄/敌方状态/能量。  

### c49 — 操戈擐甲（武卡）

- **实现**：`dealDmg(31)`。

### c50 — 枯木逢春（功卡）

- **实现**：进沉沙；`heal(12)`。

- **实现**：`unplayable: true`，`effect` 空。
