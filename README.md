# 飞白(Feibai)

**东方暗黑水墨风 · 冥府游历卡组构筑 Roguelike**

在阴阳交界处洗牌的命运：你有「气」的限制，也有「势」的爆发；刀锋上要讲究一击的伤害，纸面上还要凑近平仄——这是一款把 **武侠卡牌战斗** 与 **诗词格律(平仄)** 拧在一起的浏览器单机小品。

**在线试玩：** [GitHub Pages Demo](https://birchove.github.io/Feibai-GameJam/)

---

## 你将体验到什么

- **冥府游记**：从望乡台启程，沿山路、茶楼、荒村与鬼门关推进，在分支地图上点击当前节点进入事件或战斗，最终在奈何桥收束旅程叙事。
- **卡组即武学**：初始一副精简残卷，战胜后与悟性挂钩领取新卡，逐步养成自己的打法；卡牌分武卡、功卡、词牌与诅咒衍生物等，稀有度从低到高影响构筑上限。
- **气与势**：出牌消耗「气」；连续打出攻击牌积攒「势」，势满后下一次攻势可按规则放大伤害(含法宝等特例)，鼓励Aggro与节奏管理。
- **平仄与诗韵**：部分卡牌带「平」「仄」标记；近期打出序列若与已有诗句残篇的格律相合，可触发 **诗韵效果**(特效演出 + 实际战斗收益)。侠客信息中可查看已领悟的诗句与说明。
- **神兵与数值**：武器独立于卡组，以「神兵」形式提供力、御加成；剑流派开局即配备 **绣剑**(数据见 `WeaponDB`)。替换神兵时可在弹窗中对比取舍。
- **多敌战斗**：同一战场可出现多名敌人，需用拖拽指向目标或默认主攻对象；部分全体攻击不必选定单体。
- **视听氛围**：界面大量水墨质感背景与立绘槽位；战斗底层 Canvas 粒子与拖拽墨迹轨迹增强手感；探索与战斗使用不同的循环 BGM(世界 / 战斗 / Boss)。

以上为当前仓库逻辑下的玩法摘要，具体到每张牌与敌人技能，以 `js/data/` 内数据为准。

## 游玩流程(与实现对齐)

1. **主菜单**：「开始旅程」进入存档界面(中途可从设置返回主菜单并保留「检查点」式的界面记忆)。
2. **选择轮回**：三个「回忆」槽位；**回忆 1 / 回忆 3** 会先播放世界观 PV(可跳过)，再进入 **六道轮回** 选流派；**回忆 2** 为快捷入口，直接进入剑流派开局(跳过 PV)。
3. **六道轮回**：界面预留剑、弓、枪、毒、棍、拳六门；**当前版本仅「剑」可正常开局**，其余会提示未开放。
4. **冥府游记(地图)**：章节随进度切换；节点包含剧情事件、随机山路遭遇、修罗场与阎王等特殊战；到达终点节点可触发结局向文本。
5. **战斗中**：回合制出牌；手牌可拖拽至场上区域打出；上方状态栏显示气血、气、势与平仄简史等。
6. **战胜后**：进入结算界面，分配钱财、悟性、卡牌三选一或双选(与悟性阈值有关)、精英额外神兵、特定遭遇法宝、诗句等；可从结算页暂时返回地图查看路线。

**说明：** 本项目 **未接入 `localStorage` 持久存档**；「回忆」槽与进度均在单次会话内有效，刷新页面即重新开始。

## 操作提示

- **三生石**：全卡图鉴(按稀有度分区)，便于浏览当前版本中所有已定义卡牌。
- **侠客信息**(顶栏名片)：查看流派、属性、卡组张数、诗句、法宝、神兵与钱财；可展开诗句 / 法宝详情。
- **拖拽出牌**：将手牌拖至上半屏区域打出；需要单体指向的攻击牌请拖向对应敌人立绘区域。
- **开发者模式**(调试)：在地图界面快速连击顶栏标题可触发(详见 `js/systems/dev.js`)，默认玩家勿依赖此项通关。

## 资源与音频(部署时注意)

游戏通过相对路径加载 `assets/` 下的 PNG、MP3 等。

- **必需三类循环 BGM**：`bgm_world.mp3`(大地图与事件)、`bgm_combat.mp3`(普通战斗)、`bgm_boss.mp3`(如阎王战)；路径配置于 `js/core/audio.js`。
- **建议补齐**：`assets/PV.mp4`(开场 PV)、`assets/sfx_*.mp3`(抽牌、受击、平仄反馈等，见 `combat.js` 引用)。缺失时不会阻断逻辑，但浏览器控制台可能出现资源 404。

## 技术说明

- **无构建、无包管理**：核心玩法均为原生 **HTML / CSS / Vanilla JavaScript**，双击或通过静态服务器打开 `index.html` 即可运行。
- **外部 CDN**：使用 Font Awesome 与 Google Fonts(书法字体)增强 UI，需联网加载。
- **脚本加载顺序**：见 `index.html` 底部——`utils` → `state` → `audio` → 数据表 → `game` → `combat` → `settlement` → `map` → `fx` → `dev`。
- **主要目录**
  - `js/core/`：全局状态、工具函数、音频封装。
  - `js/data/`：卡牌、敌人、事件地图、诗句、物品与流派静态数据。
  - `js/systems/`：流程、战斗、结算、地图事件、拖拽特效与开发者面板。
  - `css/style.css`：全站样式与各 `#screen-*` 界面。
  - `assets/`：图像与音频资源。

## 本地运行

1. 克隆或下载本仓库。
2. 将完整资源放入 `assets/`(至少保证 README 上述音频与背景图存在，避免大量 404)。
3. 推荐使用 **本地静态服务器**(如 VS Code Live Server、`npx serve` 等)打开根目录，以避免部分浏览器对 `file://` 下的媒体与字体限制。
